# Pypi
- We have studied about many python libraries. But when it comes to build real applications, this may not meet the requirements, in that case we will get to know the relevance of python package index.
- Pypi is node package manager for javascript developers. It's basically a repository of python packages built by us.
- To know more you can browse in pypi.org. In that 160000 projects registered in this repository currently. 
- You can also google the best python packages for working with PDF files.
- In this section you are going to learn about all the tooling you need to install these packages.  

# Pip
- To install a package from pypi we use a tool called pip
- If you're using Mac, then use the tool called pip3
- This tool can do various things such as install packages, uninstall them, upgrading them and listing the currently installed packages.
